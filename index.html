Recommendation details

Record at least two positions to compare their acoustic characteristics.
Scoring is heuristic: 50% relative SNR, 35% relative noise and 15% spectral balance. Reverberation/RT60 is not yet included because browser playback timing and calibration need further validation.

Session report

Review the saved session and export its data. The printable report can be saved as PDF through your browser's Print dialog.

Project status

Not implemented in this web prototype: validated RT60, calibration, production SQLite/JDBC persistence, JavaFX desktop packaging and server deployment. Local browser storage is used instead.
