Method and limitations

Measurements are derived from microphone recordings. dBFS is a relative digital signal level and is not the same as calibrated dB SPL.

Spectral response uses a generated sweep reference and five band comparisons. The optional decay-time proxy is a rough tail estimate, not the ISO 3382 RT60 measurement.

Noise, playback level, microphone placement, speaker quality, and browser processing can change results. Use at least three trials at each position; do not combine sample/demo measurements with real recordings.

Storage and privacy

Room metadata and trial metrics are stored in this browser. Recorded WAV clips use local IndexedDB storage when available. No cloud upload takes place. Export important results because clearing browser data will erase local sessions.
